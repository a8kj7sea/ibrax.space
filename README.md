# Ibrax.space — Personal Portfolio

A warm, luxury-styled personal portfolio for Ibrahim Al-Athamneh, a Java Software Engineer. Built with Vue 3 and Tailwind CSS, it features nine sections — home, about, work experience, projects, skills, certifications, interests, posts, and contact — all driven by editable JSON config files so content can be updated without touching code. The design uses Cormorant Garamond and Outfit fonts on a cream/terracotta palette, includes a walking character animation, timeline views, and full SEO with JSON-LD structured data.
